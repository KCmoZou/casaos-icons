# CasaOS Icons

An icon collection for applications and services used with [CasaOS](https://casaos.io/).

## Browse the icons

Explore the repository to find an icon. Open an image and use its raw file URL in your app configuration, or download it and reference the local file.

## Contributing

Contributions are welcome. Please use descriptive filenames, submit clear images (preferably square SVG or PNG), and include source and license information when available. Only contribute assets you have permission to share.

## Usage and licensing

Icon licenses may vary. Check the information provided with each asset and follow its attribution and usage terms. If an asset has no license information, obtain permission from its owner before reuse.
